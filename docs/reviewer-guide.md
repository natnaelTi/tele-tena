# Reviewer reference guide

Accessible in the application through the bottom-right Help & tours island.

1. **General application:** inspect professional identity, qualifications and private
   resume. General approval grants clinician workspace access, not service scopes.
2. **Definition:** the medical lead reviews service requirements separately. Draft
   definitions can accept applications but do not authorize practice.
3. **Scope documents:** choose one applicant and one scope. CV and license evidence
   have different purposes; credential verification requires a License or registration
   document attached to this application. Applicant uploads are allowed in Draft or
   Clarification only. Documents remain private to owner/authorized reviewers.
4. **Credential check:** after actually checking the issuing source, record its name,
   check date, source reference and attached license. Reference identifies the registry
   record or documented reviewer check, not an API credential. Upload ≠ verification.
5. **Assessment:** scores need rationales; score evidence references are optional.
   Required identity, credential, qualification, experience, adult scope and interview
   criteria must pass. No score compensates for a failed mandatory requirement.
6. **Decision:** approve only after requirements pass; otherwise request information
   or decline with a specific reason. To request missing documents, clear unfinished
   credential verification, choose Request information, explain what is needed, then
   record. Applicant edits/uploads/resubmits; reviewer rechecks before deciding.
7. **After approval:** approved scope → offering → published availability → matching.
   Expiry/revocation blocks new work and preserves historical appointments. Vetting
   roles confer no patient-note access. Existing manual grants remain auditable.

The application wiki and this guide describe implemented controls, not independent
external credential verification or regulatory accreditation. Reviewer entries persist
between steps during the current page session; no automatic decision is made. Unsaved
review entries are not retained across reload. Provisional translations need native review.
